## STRICT COURSE SEPARATION REQUIREMENT

Each course must be completely independent and have its own dedicated section within the website.

The three main courses are:

1. **Programming Fundamentals (C++)**
2. **Programming Applications (Python)**
3. **Computer Vision (Python & OpenCV)**

**IMPORTANT: NEVER mix content, lectures, exercises, quizzes, exams, or learning progress between different courses.**

Each course must have its own:

- Dedicated course page and dashboard
- Lectures organized in the correct order
- PowerPoint presentations and PDF materials
- Topics and subtopics
- MCQ questions
- Write the Code exercises
- Trace the Code exercises
- Correct the Code exercises
- Quizzes and practice exams
- Difficulty levels (Easy, Medium, Hard)
- Student progress and scores
- Search and filtering functionality
- Admin content management section

**Course independence:** Adding, editing, or deleting content in one course must not affect the other courses.

**Navigation:** Students must first select a course, then access only that course's lectures, materials, exercises, and assessments.

**Database:** Every lesson, question, quiz, exam, and resource must be associated with the correct course using proper relational database structures.

**Admin Dashboard:** The administrator must be able to manage each course independently, including uploading PowerPoints and adding exercises specifically to that course.

The platform must support adding more independent courses in the future without restructuring the entire website.

**Final rule: Treat every course as its own independent learning environment within one unified educational platform.**
