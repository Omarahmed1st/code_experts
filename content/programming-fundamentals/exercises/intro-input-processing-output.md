## Question

A shop program reads the price of an item in pounds and the number of items bought. It multiplies them and shows the total cost on the screen.

Which part of this program is the **processing**?

## Options

- [ ] Reading the price and the number of items.
  This is the **input**: the values that go into the program.
- [x] Multiplying the price by the number of items.
  Right: processing is the work the program does on the input to get the result.
- [ ] Showing the total cost on the screen.
  This is the **output**: the result the program gives back.
- [ ] Typing the program in C++.
  Writing the code is a stage of programming, not a part of what the program does when it runs.

## Hints

- Every program has three parts: what goes in, what it does, and what comes out.
- Which part is a calculation?

## Explanation

Every program turns **input** into **output** through **processing**. Here the input is the price and the number of items, the processing is the multiplication, and the output is the total cost shown on the screen.

A good habit is to name these three parts before you plan anything. The calculation in the middle is the processing, because it changes the input into the result.
