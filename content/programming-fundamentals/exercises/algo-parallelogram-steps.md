## Question

You are drawing a flowchart. Which of these steps go in a **parallelogram**? Choose all that apply.

## Options

- [x] Read the mark
  Right: reading a value is input, and input goes in a parallelogram.
- [x] Print the total
  Right: printing a value is output, and output also goes in a parallelogram.
- [ ] total ← a + b
  This is a calculation (processing), so it goes in a rectangle.
- [ ] Is x > 0?
  This is a question with two exits, so it goes in a diamond.

## Hints

- The parallelogram is the shape for values going **in** to or coming **out** of the program.
- Which steps calculate something, and which ask a question?

## Explanation

The parallelogram is used for both **input** and **output**: reading a value (like "Read the mark" or `Input T`) and printing a value (like `Print AVERAGE`).

A calculation such as `total ← a + b` is **processing**, so it goes in a rectangle. A question such as "Is x > 0?" is a **decision**, so it goes in a diamond with YES and NO exits.
