## Question

Which sentence best describes a **program**?

## Options

- [x] A set of precise, step-by-step instructions that the computer follows exactly, in order.
  Right: a program is a list of exact steps, and the computer carries them out in the order they are written.
- [ ] A set of general ideas that the computer completes by guessing what you meant.
  The computer never guesses. If a step is not written down exactly, it does not happen.
- [ ] Only the output that appears on the screen.
  The output is what a program produces. The program is the list of steps that produces it.
- [ ] The computer's processor (the CPU).
  The CPU is the hardware that runs the program. The program is the instructions it runs.

## Hints

- Think about the recipe picture from the lecture. Is the program the meal, the kitchen, or the cooking steps?
- Does a computer ever fill in a missing step by itself?

## Explanation

A **program** is a set of step-by-step instructions that a computer follows. The computer does exactly what the steps say, in the order they are written, and it never guesses what you meant.

That is why a recipe step like "add some salt" is fine for a person but not for a computer: a program needs exact steps, like "add 5 grams of salt". The CPU is the machine that runs the steps, and the output is the result they produce; neither of them is the program itself.
