## Question

Which of these statements about flowcharts are **correct**? Pick **all** the correct ones.

## Options

- [x] An oval marks the Start or the End of the algorithm.
  Correct: every flowchart begins and finishes with an oval.
- [x] A diamond always has exactly two exits, labelled YES and NO (or TRUE and FALSE).
  Correct: a decision is a question with two possible answers, so it has two paths out.
- [ ] The step "Read the mark" goes in a rectangle.
  Wrong: reading a value is input, so it goes in a parallelogram. Rectangles are for calculations.
- [ ] Arrows can be left out when the shapes are drawn in one column.
  Wrong: without arrows the reader can't tell the order of the steps. Always draw them.

## Hints

- Think about the legend: oval, parallelogram, rectangle, diamond and arrow. What is each one for?
- Look at the "Flowchart mistakes to avoid" list in the lecture.

## Explanation

Each symbol has one job:

- **Oval:** Start and End.
- **Parallelogram:** input and output, such as "Read the mark" or "Print Area".
- **Rectangle:** a calculation, such as `area ← length * width`.
- **Diamond:** a decision, with exactly two exits, YES and NO.
- **Arrow:** the order of the steps.

So the statements about the oval and the diamond are correct. "Read the mark" in a rectangle uses the wrong shape, and a flowchart with no arrows doesn't show the order of the steps.
