## Question

Your teacher gives you a new programming problem. Following the 3-step process from the lecture, what should you do **first**?

## Options

- [ ] Open the editor and start typing C++ code.
  Code comes last. Without understanding the problem, you don't know what the code should do.
- [x] Read the problem carefully and find its inputs, outputs and rules.
  Right: step 1 is to understand the problem. You decide what the program must do before writing any code.
- [ ] Run test cases to find the errors.
  You can only test a program after it is written. Testing is part of step 3.
- [ ] Draw the flowchart of the solution.
  Planning with a flowchart is step 2. You need to understand the problem before you can plan its steps.

## Hints

- The three steps are: understand, design, implement and test.
- Can you plan the steps if you don't know what goes in and what must come out?

## Explanation

Every problem in this course is solved in the same order:

1. **Understand the problem**: find the inputs, the outputs and the rules (constraints).
2. **Design an algorithm**: plan clear, ordered steps with a flowchart or pseudocode.
3. **Implement and test**: write the code, run test cases and fix the errors.

Starting with code skips the thinking, and code written without a plan usually has to be rewritten.
