## Question

In a flowchart, which shape do you use for the step "Is the price more than 100?"

## Options

- [ ] An oval
  Ovals only mark the start and the end of the flowchart.
- [ ] A parallelogram
  Parallelograms are for input and output, such as "Read the price" or "Print the total".
- [ ] A rectangle
  Rectangles are for processing, such as a calculation. This step asks a question instead.
- [x] A diamond
  Right: a diamond asks a question and has two exits, YES and NO.

## Hints

- Does this step calculate something, or does it ask something?
- How many exits does this step need?

## Explanation

Each flowchart shape has one meaning: **oval** = start/end, **parallelogram** = input/output, **rectangle** = process, **diamond** = decision, **arrow** = the order of the steps.

"Is the price more than 100?" is a question with a yes/no answer, so it is a **decision**. It goes in a diamond, which has two exits: one path for YES and one for NO. Only one of the two paths is followed each time.
