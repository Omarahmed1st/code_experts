## Question

Which sentence about **pseudocode** is true?

## Options

- [ ] It is a programming language that the computer runs after compiling it.
  No computer runs pseudocode. It is not a real programming language.
- [x] It is structured, English-like steps that people use to plan an algorithm before writing code.
  Right: pseudocode is written for people, to plan the logic first.
- [ ] It only works for C++, so a Python programmer can't use it.
  Pseudocode is language independent: the same plan can become C++, Python, Java or any other language.
- [ ] Every line must end with a semicolon, or it is wrong.
  Pseudocode has no strict syntax rules. Semicolons are a C++ rule, not a pseudocode rule.

## Hints

- Who reads pseudocode: a person or a computer?
- Does pseudocode belong to one programming language?

## Explanation

**Pseudocode** is an informal way of describing an algorithm with simple, structured, English-like statements. It is not a real programming language, no computer runs it, and it has no strict syntax rules.

It sits between human thinking and real code. Because it focuses on the logic and not on language details, the same pseudocode can be turned into C++, Python or Java, and each line maps naturally to a line of code.
