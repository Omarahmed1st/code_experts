## Question

You are drawing the flowchart for "read a price and a quantity, and print the total cost". Which shape do you use for the step **Print total**?

## Options

- [x] A parallelogram
  Right: printing is output, and input and output both go in a parallelogram.
- [ ] A rectangle
  Rectangles are for calculations (processing), such as `total ← price * quantity`. Printing is output, not a calculation.
- [ ] A diamond
  A diamond is a decision: a question with two exits, YES and NO. Printing asks no question.
- [ ] An oval
  Ovals are only for Start and End.

## Hints

- Is printing input, processing, output or a decision?
- Which shape did the rectangle-area flowchart use for "Print Area"?

## Explanation

Each flowchart shape has one meaning: the **oval** starts and ends the chart, the **parallelogram** is for input and output, the **rectangle** is for a calculation, and the **diamond** is for a decision.

"Print total" shows a value to the user, so it is **output** and goes in a parallelogram, just like "Print Area" in the rectangle-area flowchart. Putting it in a rectangle is a common mistake: rectangles are only for calculations.
